# VLSI Design Internship – Basic Logic Gates Simulation

## About the Project
This project is part of my VLSI Design Virtual Internship at **Maincrafts Technology**.

The objective is to design and simulate basic digital logic gates using Logisim and understand their working through truth table verification.

## Software Used
- Logisim – Digital Logic Circuit Simulator

## Logic Gates Implemented
1. AND Gate
2. OR Gate
3. NOT Gate
4. NAND Gate
5. NOR Gate
6. XOR Gate

## Additional Circuit
- Half Adder – Implementation of Sum and Carry outputs using XOR and AND gates.

## Learning Outcomes
- Understanding basic digital logic gates.
- Designing and implementing logic circuits.
- Verifying outputs using truth tables.
- Developing practical knowledge of digital electronics.

## Repository Structure
- `Circuit_Files/` – Logisim circuit files (.circ)
- `Screenshots/` – Circuit implementation screenshots (.png)
